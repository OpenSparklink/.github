# OpenSparklink 组织主页配置

本仓库管理 [OpenSparklink 的 GitHub 组织主页](https://github.com/OpenSparklink)。

- [`profile/README.md`](profile/README.md)：面向公开访客的组织介绍、项目导航、实测 IQ 数据入口和协作说明。
- [`profile/assets/banner.svg`](profile/assets/banner.svg)：组织主页横幅，采用静态 SVG。

新增项目入口前，确认目标仓库和文档已公开，并核对项目说明及链接。项目功能、实验参数、数据版本和许可证等详细信息由各项目仓库维护。

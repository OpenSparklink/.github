# 设计历史

本目录保存 OpenSparklink 组织标识的探索过程。当前采用的版本是 [`../assets/logo.svg`](../assets/logo.svg)：C 方案的 O/S 融合图形与 04 星火橙配色。

- `concepts/`：文字生成图片得到的 A「无线星火」、B「开放连接」、C「O/S 融合」原始概念图，以及完整生成提示词。原始图片保持生成时的样貌。
- `c-svg/`：选定 C 后的手工 SVG 重绘及透明版、小尺寸预览。
- `palettes/`：六组配色的 SVG、PNG、颜色清单、完整对比图与独立交互对比页。各方案使用相同的四条曲线。
- `profile-banner-before.svg`：启用星火橙前的组织主页横幅。

初期概念图由 AI 辅助生成；定稿使用独立、可编辑的原生 SVG 路径。组织负责人先选择 C 方案，再选择 04 星火橙，并于 2026-11-16 要求正式采用。
